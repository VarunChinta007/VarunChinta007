## 📈 Data Science & Machine Learning Workflow

```text
┌─────────────────┐     ┌─────────────────┐     ┌──────────────────────┐
│  Data Ingestion │ ──> │ Data Wrangling  │ ──> │   Exploratory Data   │
│   (CSV, SQL)    │     │ & Preprocessing │     │    Analysis (EDA)    │
└─────────────────┘     └─────────────────┘     └──────────────────────┘
                                                           │
                                                           ▼
┌─────────────────┐     ┌─────────────────┐     ┌──────────────────────┐
│ Deployment & BI │ <── │Model Evaluation │ <── │ Feature Engineering  │
│ Dashboards / UI │     │& Optimization   │     │ & Model Training     │
└─────────────────┘     └─────────────────┘     └──────────────────────┘
```

- **Data Cleaning & Wrangling:** Handling missing values, outlier detection, data type casting, categorical variable encoding (One-Hot, Label Encoding), and standardization/normalization.
- **Exploratory Data Analysis (EDA):** Univariate, bivariate, and multivariate analysis; correlation heatmaps, feature distribution analysis, and statistical hypothesis verification.
- **Model Training & Evaluation:** Implementing linear models, tree-based models, and ensemble classifiers; evaluating via Confusion Matrix, Precision, Recall, F1-Score, ROC-AUC, and Mean Squared Error (MSE).
- **Business Intelligence & Reporting:** Designing clear, actionable dashboards in Power BI and interactive prototypes with Streamlit.
